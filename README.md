# FEROZ AI TRADER

Android starter project for a black-and-gold XAUUSD demo-analysis interface.

## Important limitations
- This first build is an offline demo shell.
- It does not connect to MetaTrader 5, a broker, or live market prices.
- It does not place trades and must not be treated as financial advice.
- Live data and secure broker-side execution require a separately configured, tested backend and broker integration.

## Build
Run the GitHub Actions workflow **Build Android APK**. Download the generated APK from the workflow run's Artifacts section.
